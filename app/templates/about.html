About PromptGuard

PromptGuard is an independent, educational AI security firewall that protects LLM applications from direct and indirect prompt injection. It combines two separate security ideas: detection (does this input look malicious?) and capability control (even if a malicious instruction reaches the model, what is the model actually allowed to do?).

Defense in depth

No detector catches every prompt injection - it is an adversarial problem, and paraphrased or novel attacks can bypass rules. PromptGuard therefore layers independent controls so that a miss in one layer can be caught by another.

Operating modes

  • LEARNING - detect and log only; nothing is blocked.
  • MONITOR - detect and warn; blocks are downgraded to warnings.
  • ENFORCE - full policy: ALLOW / WARN / SANITIZE / BLOCK.

Modes affect the input detector only. The tool firewall and output firewall are always enforced: detection is tunable, capability control is not.

Trust model (provenance)

TRUSTED_SYSTEMUSER_INPUT UNTRUSTED_DOCUMENTEXTERNAL_CONTENTTOOL_OUTPUT

Untrusted content is wrapped in nonce-keyed fences and treated as DATA. Anything derived from it stays tainted. Sensitive tools cannot be triggered by tainted content.

Reference
